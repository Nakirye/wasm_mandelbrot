Fireworks: objects vs. typed arrays vs. Wasm

JavaScript (objects) One object per particle, the usual way to write it. Burnt-out sparks have to be removed by the garbage collector, which causes short pauses ("slowest frame").
JavaScript (typed arrays) No objects: one number array per property (xs, ys, …), particle i is position i in every array.
WebAssembly The same table layout as the typed arrays, inside the Wasm memory. Wasm has no JavaScript objects, so this is the natural way to write it there.
